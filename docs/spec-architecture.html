Explore the repository structure
src/ · TypeScript CLI and orchestration
  • index.ts → cli.ts — executable and command registration
  • shell.ts / agent.ts — terminal routing and conversation control
  • local-agent-client.ts / agent-model.ts — local agent loop and provider selection
  • agent-tools.ts / agent-approval.ts — tool schemas, proposals and approval
  • local-pipeline-action.ts / spec-workspace.ts — pipeline previews and reviewed spec edits
  • agent-store.ts / config.ts / paths.ts — conversation, credentials and paths
  • pipeline.ts — shared pipeline contract and execution planning
  • client.ts — account HTTP API
commands/ · user-facing actions
  • pipeline.ts — init / validate / plan / run
  • spec.ts — shared CLI and shell review
  • local.ts — local runtime command forwarding
  • cloud.ts / auth.ts / publish.ts — account operations
local-runtime/ · execution machinery
  • contracts.ts / local-project.ts — strict schemas, parsing and shared spec validation
  • orchestrator.ts / foundation-runner.ts — separate engine coordinators
  • dataset.ts / evaluation.ts — compile data, score predictions
  • process-training.ts / process-runner.ts / gpu-executor.ts — process lifecycle and transport
  • store.ts / artifacts.ts / model-registry.ts — records and artifact integrity
  • model-server.ts / serving-runtime.ts — verified serving process
training/ · independently locked runtimes
  • adapter/src/ — train.py, sft_data.py, evaluate.py, prefetch.py, serve.py, foundation_export.py
  • foundation/src/ — train_tokenizer.py, model.py, pretrain.py, finetune.py, rl.py, evaluate.py, checkpoint.py, data.py
  • serving/ — vLLM dependency environment
  • Each runtime has its own pyproject.toml and uv.lock.
examples/ and tests
  • examples/local-runtime/ — adapter/foundation specs and local/AWS configs
  • src/__tests__/ — CLI, agent and workflow tests
  • test/local-runtime/ — runtime contracts
  • training/*/tests/ — Python regression tests
